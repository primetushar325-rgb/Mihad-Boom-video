# VideoStore BD - GitHub Pages Ready Website

আপনার ইউটিউব শর্টস, কোর্স এবং ভাইরাল লং ভিডিও বিক্রির জন্য একটি সম্পূর্ণ রেডি ওয়েবসাইট তৈরি করা হয়েছে। এটি সম্পূর্ণ **HTML, Tailwind CSS ও JavaScript** দিয়ে তৈরি, তাই কোনো ব্যাকএন্ড বা ডেটাবেস ছাড়াই সরাসরি **GitHub Pages**-এ ফ্রিতে হোস্ট করতে পারবেন।

---

### 📂 ফাইলের তালিকা (3টি HTML পেজ):
1. **`index.html`** ( হোম পেজ ):
   - ক্যাটাগরি সিস্টেমসহ YouTube Shorts সার্ভিস কার্ড (যেমন: Motivation, Finance, AI Faceless, Anime ইত্যাদি)।
   - YouTube Course ক্যাটাগরি সেকশন।
   - Viral Long Video ক্যাটাগরি সেকশন।
   - বিকাশ/নগদ পেমেন্ট ও অর্ডার পপআপ মডাল।

2. **`demo.html`** ( ডেমো ভিডিও পেজ ):
   - ডেমো ভিডিও বা শর্টস প্রিভিউ দেখানোর জন্য রেডি গ্রিড।

3. **`free.html`** ( ফ্রি সার্ভিস পেজ ):
   - ফ্রি শর্টস ডাউনলোড, ফ্রি পিডিএফ গাইড এবং টেলিগ্রাম কমিউনিটি লিংক।

---

### 🚀 যেভাবে GitHub-এ আপলোড করবেন (GitHub Pages):
1. [GitHub.com](https://github.com)-এ একটি নতুন **Repository** তৈরি করুন (যেমন: `videostore-bd`).
2. আপনার ৩টি ফাইল (`index.html`, `demo.html`, `free.html`) সরাসরি সেই রিপোজিটরিতে **Upload** করুন।
3. রিপোজিটরির **Settings** > **Pages**-এ যান।
4. Branch-এ `main` (বা `master`) সিলেক্ট করে **Save** করুন।
5. কয়েক সেকেন্ডের মধ্যে GitHub আপনাকে একটি লাইভ লিংক দিয়ে দেবে (যেমন: `https://yourusername.github.io/videostore-bd`)!

- এই কোডগুলো অত্যন্ত পরিষ্কার এবং কমেন্ট করা। আপনি যেকোনো AI (যেমন ChatGPT, Claude, Gemini) কে এই ফাইলগুলোর কোড কপি করে দেখাতে পারেন এবং বলতে পারেন: *"এই টেক্সট বা প্রাইস চেন্জ করে দাও"* অথবা *"নতুন একটা ক্যাটাগরি যোগ করে দাও"*। AI খুব সহজেই আপনাকে আপডেট কোড লিখে দেবে।
